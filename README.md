# CSS Lab — Practice Portfolio

A responsive one-page website demonstrating the 15 CSS Basics practice exercises:
- Beginner (1–5): text styling, class selector, box model, colours, link hover.
- Intermediate (6–10): fixed positioning, profile card, Flexbox navigation, Grid layout, media queries.
- Challenging (11–15): responsive gallery, sticky header, animated button, Grid landing page, responsive cards.

## Run locally
Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Publish
1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
3. No build command is needed; this is a static HTML/CSS/JS site.

## Customise
Edit `index.html` for the text and `css/style.css` for the design.
